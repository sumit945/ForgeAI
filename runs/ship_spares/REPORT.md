# ForgeAI run report - SparePartAssistant

**Brief:** Build an assistant for technical superintendents who buy ship spares. It should look up parts in the spares catalogue (price, lead time, stock), explain each approved supplier's terms (payment, freight, returns, warranty, surcharges), and work out the total cost of an order and which approval level it needs. Be precise and concise. It must not advise on fuel prices or charter decisions.

**Result:** final overall pass rate **95%** (20/21 cases; 95% interval 77%-99%), dev 93%, hold-out 100%. Baseline was 95%. Optimizer stopped because: dev pass-rate 93% >= target 90%.

> This number is a measurement on an eval set generated by a small model from the same documents. Treat it as a regression signal, not a guarantee. With 21 cases one case moves the score by 5 points.
